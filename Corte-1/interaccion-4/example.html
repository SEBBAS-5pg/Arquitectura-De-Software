Arquitectura (Contexto + Estrategias)

El contexto CheckoutPricer delega el cálculo del descuento a la estrategia seleccionada. Cambiar la estrategia no requiere if/else gigantes; solo se reasigna el objeto estrategia. 

// Interfaz objetivo
interface DiscountStrategy { compute(cart): {discount:number, reason:string}; }

// Estrategias concretas:
- SinDescuento      -> baseline, no aplica descuento.
- PorcentajeFijo    -> 10% del subtotal.
- PorVolumen        -> por tramos: 3+, 5+, 10+ items.
- MLSimulado        -> ajusta % según "carga" del sistema (demo).

// Contexto:
class CheckoutPricer {
  setStrategy(strategy) { this.strategy = strategy; }
  price(cart) {
    const subtotal = sum(cart);
    const { discount } = this.strategy.compute(cart);
    return { subtotal, discount, total: subtotal - discount };
  }
}
