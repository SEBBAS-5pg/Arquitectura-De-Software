Desafíos de Seguridad en la Migración a Serverless

Análisis basado en el AWS Well-Architected Framework

La migración a arquitecturas Serverless en AWS transfiere la gestión operativa del servidor al proveedor, pero incrementa la responsabilidad del arquitecto en la configuración granular de permisos y la protección de datos distribuidos.

Desafíos Clave

Área Riesgo Principal
Gestión de IAM Roles con permisos excesivos (Over-privileged roles).
Amazon S3 Exposición accidental por políticas de bucket laxas.
AWS Lambda Explotación de Cold Starts y denegación de servicio (DoS).

Ejemplo: Política de Menor Privilegio (DynamoDB)

{
  "Version": "2012-10-17",
  "Statement": [{
    "Sid": "DynamoReadOnly",
    "Effect": "Allow",
    "Action": [
      "dynamodb:GetItem", 
      "dynamodb:Query"
    ],
    "Resource": "arn:aws:dynamodb:*:*:table/MiTabla",
    "Condition": {
      "StringEquals": {"aws:PrincipalTag/Role": "lector"}
    }
  }]
}
