Descripción

El cliente (esta página) trabaja con PaymentsService que usa JSON.

El gateway legacy solo acepta SOAP/XML.

El Adapter traduce JSON ↔ XML y conecta ambos sistemas sin modificar el legado.

Arquitectura
  • legacyGatewaySOAP.js: simula SOAP/XML.
  • paymentsAdapter.js: adapta JSON→XML.
  • app.js: cliente REST.
